Open chess model · plays the style you describe

Tell a chess model how to play.

CHSM8 is a 210M-parameter chess transformer that picks its moves from a free-text description of a playing style. It plays without search, and every move is legal by construction. Weights, datasets, labels and demos are open.

What it does

Chess models trained on human games now play well without search, but none of them lets you simply say how they should play. Rating-conditioned models control strength and player-specific models control identity; CHSM8 accepts an open-ended request. It is built for sparring and fun rather than grandmaster-level play, and it stays strong without search.

Text in, move out

A frozen EmbeddingGemma-300m encodes the prompt. Gated cross-attention in the top 6 of 12 decoder layers reads every token of it.

Legal by construction

Each move is a tuple (source, destination, piece, promotion) with one output head per field. The model scores only the legal moves of the position.

No search

One forward pass per move: the model plays its highest-scoring legal move. That is fast enough to run in a browser tab.

Try it

Play against CHSM8, give each side a style prompt, and see the probabilities behind every move.

In your browser

No install. The model runs in this tab on WebGPU, or on the CPU with WebAssembly, after a one-time download of about 480 MB (8-bit weights, fp32 compute).

On your GPU

Full-precision PyTorch on CUDA, Apple MPS or CPU. Clone the code, run python server.py and choose "My server".

The move tokenizer, live

Any notation in (SAN, LAN, UCI, numbered PGN with comments and variations, mixed within one game), the exact model input out. Each move becomes a 15-bit id (6 bits from-square, 6 bits to-square, 3 bits promotion) and a model row (kind, src, dst, piece, promo). This box runs the Rust tokenizer compiled to WebAssembly, the same code the demos use.

Use it

The models are project-specific PyTorch checkpoints on Hugging Face; the inference code is one file, chsm8.py, in the code repository.

Score moves from Python

# needs a Rust toolchain for the tokenizer (https://rustup.rs)
git clone https://github.com/nov3o/llm_chess-demo
cd llm_chess-demo && pip install -r requirements.txt
hf auth login   # once: the prompt encoder is gated
from chsm8 import CHSM8

model = CHSM8.from_pretrained()   # LegumMagister/chsm8
moves = model.score("1. e4 e5 2. Nf3",
    "castle queenside and storm the enemy king with your pawns")
print(moves[:3])   # legal moves with log-probabilities, best first

An empty prompt gives the model's own play. Other weights: CHSM8.from_pretrained("LegumMagister/chsm8-sft"), or filename="full_pass/model.pt" for the full-pass DPO model. Accept the EmbeddingGemma-300m license on Hugging Face first.

How it is built

Standard components at every stage: a Llama-style decoder, GPT-3 style schedules, Flamingo-style gated cross-attention, distilled labels and DPO. Design choices at each stage were made by fixed-budget automated search loops in the style of autoresearch. Elo is without a prompt, against Stockfish at UCI_Elo 2000. Select a stage.

The cost of following risky prompts

Told to attack at all costs and sacrifice material, chsm8 does, and without search it loses about 150 Elo against an accurate engine (SFT: about 40). Training games labeled as sacrificial were not lost more often.

Strong without search

chsm8-pt against other public models trained without preference tuning, rewards or search: 200 games each, from 100 openings with colors swapped. Elo advantage with 95% CI. It wins every match, including against a 2.8B model.

Strength during pretraining

200 games per checkpoint (±50 Elo); final model 999 games, 1837 Elo (95% CI 1817 to 1856). The pass was restarted at 60% with the remaining data reshuffled, after a loss bump tied to the 2021-09 to 2022-05 Lichess months.

Player prompts

On about 1,000 held-out games for each of the 20 top players with the most data, "play like {player}" with the right name makes the player's real moves more likely than the same wording with another top player's name, for all 20 players.

Across all 99 players, the right name wins in cross-entropy for 94 (SFT) and 96 (DPO). The effect is modest because top players differ little in their moves.

Labels that agree with the board

Gemma-4-31B described 3.02M game sides from their moves plus a card of features measured on the board. A Gemma-3-1B student, distilled from the 2.4M teacher sets that contradict nothing on the board, labeled the rest.

The student carries as much signal about the game as its teacher. A second teacher, Apertus-70B, wrote vivid labels that carried 4 to 5 times less signal, so it was dropped.

Limitations

  • No search. The model can miss tactics an engine would see, and risky prompts cost strength against an accurate opponent.
  • An alignment tax. Style SFT costs about 45 Elo without a prompt (1792 against 1837), because the decoder learns to fit the description as well as the move.
  • No weak-play conditioning. Every described player is rated 2200 or higher, so asking for weaker or stronger play does not change strength.
  • Modest player effect. Player prompts work for 94 of 99 players, but move match rises by only about one point.
  • Proxy metrics. Style adherence is measured on a handful of prompts with hand-written metrics, not a validated judgment of style.
  • English prompts only; standard chess only.
